# Tesu-Season-Report
Collection of tournament performance reports for Badminton Club Tervasulka,
one report per season, rendered into `Output/`: `Output/index.html` is the
ongoing season (refreshed monthly with `src/refresh.py`), finished seasons are
frozen as `Output/<season>.html` (e.g. `2025-26.html`), and
`Output/tervasulka-report.html` bundles all seasons into one shareable file.
Build docs: `docs/README.md`.
